## 故事

511与513拥有相同的面孔与起点。大学四年里，他们对拖延、失败、学习与求助做出的回应，逐渐留下不同的痕迹。

影片以面试切入，回到大学生活中的关键选择，再以项目资料和简历呼应开头。编号 **511＋513＝1024** 与赛事主题形成联系。

我们希望观众记住：**四年不能重来，下一步，仍然可以选择。**
