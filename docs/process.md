# 创作过程

## 故事与人物

作品把同一个人的大学四年放在两个平行世界中，通过日常选择和面试状态形成对照。511会拖延，也有焦虑与改变的愿望；513会失败，但愿意继续尝试。

## 从剧本到影像

千问生成文案脚本，豆包制作主人公形象，Codex整理镜头提示词和制作说明，WorkBuddy用于视频生成。团队按八场分工，每人负责两场，再围绕同一故事整合素材。

42条提示词描述的是镜头方案。生成素材的数量、可用片段数量与最终镜头数量需要分别统计，仓库不把它们混为一谈。

## 制作中的检查思路

人物一致性需要结合共同的角色参考图核对；镜头衔接需要检查景别、动作和时间线；课程页面、简历和项目资料需要核对文字及道具连续性。这些是制作方案与复盘方向，不代表每一处问题都已经消除。

## 从方案到最终剪辑

早期剧本包含511重新学习、敲下第一行代码等设计。发布的最终影片如何收束，以Release中的实际画面为准。保留早期剧本和分镜，便于了解素材如何从创作意图进入剪辑。

最终作品约3分05秒。主旨保留为“四年不能重来，下一步，仍然可以选择”。

## 继续改进的方向

后续可以进一步说明剧中项目的功能，让人物与道具在跨场次时保持更清楚的联系，并记录每次生成、筛选与修改的依据。仓库目前没有整理可复核的底层模型、生成次数、费用或成功率统计。
